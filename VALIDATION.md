# Проверка версии 0.1.0

Дата: 13 ноября 2026.

## Выполнено

- `npm run test:core`: 17 проверок пройдены на Node.js 24.15.0. Адреса, несколько получателей, ограничения файла, маршруты, агрегированный статус, экранирование HTML и стандартный тест SHA-256.
- Все 8 файлов TypeScript/TSX, включая Edge Function, успешно разобраны локально доступным Babel parser с поддержкой TypeScript/JSX. Это проверка синтаксиса, не проверка типов TypeScript.
- `node --check public/sw.js`: синтаксис service worker корректен.
- Созданы PNG-иконки PWA 192×192 и 512×512 и манифест.

## Не выполнено в текущем окружении

- `npm install` не завершён: npm registry недоступен (`ECONNREFUSED` в ограниченной сетевой среде). Из-за отсутствия зависимостей не выполнены `npm test` (Vitest), `npm run build` (tsc/Vite), браузерная проверка и тест реальной установки PWA.
- Supabase, SMTP и Resend пока не подключены. SQL-миграция, RLS, Realtime, вход из письма, Edge Function и доставка настоящих писем требуют интеграционной проверки по README.
- Создан открытый репозиторий https://github.com/FoxyEvilMP/DemoE . README и проприетарная LICENSE опубликованы и прочитаны обратно через GitHub. Загрузка остальных исходников заблокирована: GitHub API возвращает 403 при записи, а браузерная загрузка требует разрешения «Allow access to file URLs» для расширения ChatGPT. GitHub Release и GitHub Pages пока не созданы.
- Добавлена поддержка SMTP Mail.ru (TLS, порт 465) и миграция состояния `uncertain`: при неопределённом результате SMTP автоматический повтор не выполняется. Живая SMTP-доставка не проверена без настройки сервера и пароля приложения.

Проект передаётся как исходники для первого проверяемого релиза, а не как уже опубликованное приложение. После установки зависимостей сначала выполните `npm test` и `npm run build`, затем подключите сервисы и пройдите сценарий в два устройства.

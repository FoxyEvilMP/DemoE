# Е-Шлюз · 0.1.0

Первая версия PWA-демо без 1С: обмен PDF/DOCX/XML, несколько получателей, ответные демо-подписи и отказы, маршрутизация, карантин и ZIP-пакет.

Публичный репозиторий DemoE. Проприетарная лицензия, все права защищены. Поддержан Mail.ru SMTP; адреса получателей могут принадлежать любым почтовым сервисам.

Для обмена между устройствами настройте Supabase, SMTP и Resend по README. Без этих подключений доступен локальный режим. Ввод email в приложение не подключает почтовый сервис.

КЭП, ГОСТ, TSP, PKI и внешние операторы имитируются. .sig — демонстрационные JSON-макеты, не юридически значимые подписи. Транспорт файлов — Supabase.

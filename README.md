# DemoE · Е-Шлюз

PWA-демо обмена документами: несколько получателей, маршрутизация, проверки, карантин, ответное подписание и ZIP-пакет. Без интеграции с 1С.

[Открыть приложение](https://foxyevilmp.github.io/DemoE/)

## Как пользоваться

1. Откройте приложение и нажмите «Открыть локальное демо». Для настоящего обмена после подключения сервера войдите по ссылке из письма на свой email.
2. Нажмите «Новый документ», укажите до 10 получателей и загрузите PDF, DOCX или XML до 10 МБ. Можно выбрать демо-шаблон.
3. Заполните реквизиты и нажмите «Подписать и отправить». Демо-PIN: `12345678`.
4. Получатель открывает документ во «Входящих», подписывает в ответ или отказывается с указанием причины. В локальном демо переключайте участников в верхней полосе.
5. В карточке доступны статусы адресатов, история, SHA-256, оригинал и ZIP-пакет. Для показа ошибки выберите карантин при отправке, для маршрута через демо-СБИС — УПД.

Установка: меню браузера → «Установить приложение». На iPhone: Safari → «Поделиться» → «На экран Домой».

## Статус и настройка

Исходники опубликованы. Сборка и тесты пройдены в GitHub Actions. Пока Supabase и SMTP не подключены, доступно локальное демо без настоящих писем и обмена между устройствами. Для онлайн-обмена нужен интернет; адреса пользователей могут принадлежать любым почтовым сервисам. Отправка поддерживает Mail.ru SMTP. [Инструкция подключения](docs/SETUP.md).

КЭП, ГОСТ, TSP, PKI и внешние операторы имитируются. `.sig` — демо-запись, а не юридически значимая подпись. Файлы и SHA-256 настоящие.

# DemoE · Е-Шлюз

PWA-демо обмена документами: отправка нескольким получателям, маршрутизация, проверки, карантин, ответное подписание и скачивание пакета обмена. Без интеграции с 1С.

## Как пользоваться

1. Откройте опубликованную PWA. Пока сервер не подключён, используйте кнопку «Открыть локальное демо».
2. Для настоящего обмена введите свой email и перейдите по ссылке из письма. Подходит Mail.ru, Gmail, Яндекс и любой другой почтовый сервис.
3. Нажмите «Новый документ», укажите до 10 получателей, загрузите PDF, DOCX или XML до 10 МБ и заполните реквизиты. Можно выбрать демо-шаблон.
4. Нажмите «Подписать и отправить». Демо-PIN: 12345678.
5. Получатель входит со своим email и открывает файл во «Входящих». Он может подписать в ответ или отказаться с указанием причины.
6. В карточке доступны история, статусы адресатов, проверка SHA-256, скачивание оригинала и ZIP-пакета.

Для демонстрации ошибки выберите карантин при отправке. Для маршрута через демо-коннектор СБИС выберите УПД. В локальном режиме переключайте участников кнопкой в верхней полосе; письма не отправляются.

Установка на телефон: меню браузера → «Установить приложение». На iPhone: Safari → «Поделиться» → «На экран Домой». Для обмена нужен интернет.

## Статус

Исходники подготовлены; загрузка проекта, публикация PWA и GitHub Release ещё не завершены. Для онлайн-обмена требуется подключить Supabase и SMTP. Письма от приложения могут отправляться через Mail.ru, адреса получателей могут быть любыми. Пароль отправителя хранится только на сервере.

КЭП, ГОСТ, TSP, PKI, семантические проверки и внешние операторы имитируются. Реальны файлы и SHA-256. Архив и .sig не являются юридически значимыми доказательствами или подписями.
